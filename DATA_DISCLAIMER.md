# Data Disclaimer

This project is a Noice-inspired recommendation system created for portfolio and educational purposes.

- Content metadata is based on publicly observable Noice catalog-style information.
- User listening interaction events are synthetically generated to simulate recommendation-system workflows.
- This project does not use private, internal, login-protected, or personally identifiable Noice user data.
- This project is not affiliated with, endorsed by, sponsored by, or officially connected to Noice.
- The dataset and model are intended only to demonstrate an end-to-end audio recommendation pipeline.
